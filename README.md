# 🛋 Телеграм-бот мебельной компании

Готовый бот-каталог для мебельного бизнеса. Клиенты листают категории и карточки товаров с фотографиями, видят ваши контакты и оставляют заявки на сотрудничество. Вы управляете каталогом прямо из Telegram, без сайта, админок и программистов.

## Что умеет бот

**Для клиентов**

- Каталог мебели по категориям с карточками товаров: фото, описание, страна производства, дата добавления.
- Листание товаров кнопками ◀️ ▶️ и просмотр всех фотографий товара (до 10 штук).
- Раздел «О компании / Контакты» и ваши контакты (телефон, WhatsApp, Telegram, Instagram) прямо в карточке каждого товара.
- Форма «Сотрудничество»: клиент оставляет имя, телефон и сообщение.

**Для вас (администратора)**

- Добавление и удаление категорий и товаров с фотографиями, всё кнопками в чате.
- Мгновенное уведомление в Telegram о каждой новой заявке на сотрудничество.
- Список заявок с отметками «новая» и «обработана».
- Доступ к панели только у тех, чьи ID вы указали. Остальным бот отвечает «нет доступа».

**Технически**

- Работает круглосуточно на обычном компьютере, сервере (VPS) или в Docker.
- База данных SQLite хранится в одном файле, отдельный сервер баз данных не нужен.
- Подробный журнал работы (`logs`) для быстрой диагностики проблем.
- Ошибки не «роняют» бота: пользователь видит понятное сообщение, а подробности попадают в лог.

## Как это выглядит для клиента

Клиент открывает бота и нажимает **/start**. Появляется главное меню:

- кнопки со всеми вашими категориями (они берутся из базы, то есть вы сами решаете, какие они);
- **ℹ️ О компании / Контакты**;
- **🤝 Сотрудничество**.

### Каталог

Дальше путь зависит от типа мебели, который вы указали при создании категории:

| Тип мебели в категории | Что выбирает клиент дальше |
|---|---|
| Спальная мебель, Мягкая мебель, Столы и стулья | Страна производства: Россия или Турция |
| Кухонная мебель | Тип кухни: Прямая или Угловая (страна всегда Россия) |
| Тумбы и комоды, Кровати, Матрасы, Шкафы | Сразу список товаров |

Карточка товара показывает:

- фото и описание, которые ввели вы;
- страну производства или тип кухни, дату добавления;
- ваши контакты для заказа (из настроек `.env`);
- номер товара («Показано 2 из 7») и кнопки ◀️ ▶️ для листания;
- кнопку **«📷 Посмотреть подробнее»**, если у товара больше одной фотографии.

Везде есть кнопка «⬅️ Назад»: клиент не потеряется в меню.

### Сотрудничество

Клиент вводит имя, телефон (номер проверяется на корректность, можно поделиться контактом кнопкой Telegram) и короткое сообщение. После отправки:

- клиент видит подтверждение и возвращается в меню;
- заявка сохраняется в базе;
- **каждому администратору приходит уведомление** с именем, телефоном и текстом заявки.

## Панель администратора

Открывается командой **/admin_panel** или кнопкой «⚙️ Настройки бота» в главном меню. Кнопка видна только администраторам.

| Раздел | Что можно сделать |
|---|---|
| ➕ **Добавить категорию** | Ввести название (до 50 символов), выбрать тип мебели (от него зависят подкатегории), добавить необязательное описание (до 200 символов), проверить и подтвердить. |
| 🪑 **Добавить мебель** | Выбрать категорию, указать страну или тип кухни, написать описание (до 700 символов: название, габариты, материал, цена), загрузить от 1 до 10 фото и нажать «Завершить добавление». |
| 🗑 **Удалить мебель** | Список товаров по страницам, выбор товара и подтверждение удаления. Фото удаляются вместе с товаром. |
| 🗂 **Удалить категорию** | Бот предупредит, сколько товаров удалится вместе с категорией, и попросит подтверждение. Действие необратимо. |
| 📋 **Список категорий** | Все категории с типами и описаниями. |
| 🤝 **Заявки** | Список заявок (по 5 на странице), статус 🔵 новая / ✅ обработана, кнопка «Отметить обработанной». |

На каждом шаге есть кнопка **«❌ Отменить»**, и ничего не сохранится, пока вы не подтвердите.

## Что нужно для запуска

1. **Компьютер или сервер**, который будет включён, пока бот должен работать (Windows, Linux или macOS). Для постоянной работы удобнее недорогой VPS.
2. **Python 3.11 или новее**. Скачать: <https://www.python.org/downloads/>.
   При установке на Windows поставьте галочку **«Add Python to PATH»**.
3. **Poetry** (менеджер зависимостей). Установка: `pip install poetry` (или по [официальной инструкции](https://python-poetry.org/docs/#installation)).
   *Если запускаете через Docker, Python и Poetry устанавливать не нужно, см. [ниже](#запуск-через-docker).*
4. **Токен бота** от Telegram:
   - откройте в Telegram [@BotFather](https://t.me/BotFather);
   - отправьте команду `/newbot` и следуйте подсказкам (имя и логин бота);
   - в конце BotFather пришлёт токен вида `123456789:AAAbbbCCC...`. Сохраните его и никому не показывайте.
5. **Ваш Telegram ID** (число): напишите боту [@userinfobot](https://t.me/userinfobot), он ответит вашим ID.

## Быстрый запуск

Откройте терминал в папке проекта (на Windows: зайдите в папку, нажмите на адресную строку проводника, введите `cmd` и Enter).

### Windows

```bat
poetry install
copy .env.example .env
notepad .env
poetry run python main.py
```

### Linux / macOS

```bash
poetry install
cp .env.example .env
nano .env
poetry run python main.py
```

Что делают эти команды: Poetry создаёт изолированное виртуальное окружение, устанавливает все библиотеки из `poetry.lock`, вы создаёте файл настроек `.env` и запускаете бота. В `.env` заполните токен и свой ID (см. следующий раздел).

**Бот запущен, если** в консоли появились строки:

```
🚀 Бот мебельной компании успешно запущен!
Run polling for bot @имя_вашего_бота
```

Откройте бота в Telegram и нажмите **/start**.

**Остановка:** нажмите **Ctrl+C** в окне с ботом (не закрывайте окно крестиком, иначе журнал сохранится только при следующем запуске).

**Следующие запуски:**
```bash
poetry run python main.py
```
*(или активируйте виртуальное окружение командой `poetry shell` и запускайте `python main.py`).*

## Настройка файла .env

Файл `.env` лежит в папке проекта (создаётся копированием `.env.example`). Это текстовый файл, открывайте его Блокнотом. Каждая настройка записывается в формате `ИМЯ=значение`, без кавычек и пробелов вокруг `=`.

| Настройка | Обязательна | Описание | Пример |
|---|---|---|---|
| `BOT_TOKEN` | **Да** | Токен от @BotFather | `123456789:AAAbbbCCC` |
| `ADMIN_IDS` | **Да** | Telegram ID администраторов через запятую | `111111111,222222222` |
| `CONTACT_PHONE` | Нет | Телефон для заказа | `+7 900 123-45-67` |
| `CONTACT_WHATSAPP` | Нет | WhatsApp | `+7 900 123-45-67` |
| `CONTACT_TELEGRAM` | Нет | Ваш Telegram | `@my_shop` |
| `CONTACT_INSTAGRAM` | Нет | Instagram | `@my_shop` |

Контакты, которые вы заполните, показываются в каждой карточке товара и в разделе «О компании». Пустые не отображаются.

После изменения `.env` бота нужно перезапустить.

> ⚠️ **Важно:** каждый администратор должен хотя бы один раз отправить боту `/start`. Иначе Telegram не позволит боту написать ему уведомление о заявке.

## Запуск через Docker

Подойдёт для сервера: бот сам перезапускается после сбоя или перезагрузки машины.

1. Установите [Docker](https://docs.docker.com/get-docker/).
2. Создайте и заполните `.env` (как описано выше).
3. Запустите:

```bash
docker compose up -d --build
```

Полезные команды:

```bash
docker compose logs -f bot    # смотреть журнал в реальном времени
docker compose restart bot    # перезапустить
docker compose down           # остановить
```

База данных и логи сохраняются в папке `data/` рядом с `docker-compose.yml` (логи в `data/logs/`) и не пропадают при обновлении или пересоздании контейнера.

## Как пользоваться ботом после запуска

Первый запуск (пустой каталог):

1. Напишите боту `/start`, затем `/admin_panel`.
2. **Создайте категорию:** «➕ Добавить категорию», например «Диваны» с типом «Мягкая мебель».
3. **Добавьте товар:** «🪑 Добавить мебель», выберите категорию и страну, напишите описание, отправьте фото и нажмите «✅ Завершить добавление».
4. Нажмите «⬅️ Назад» и проверьте, как каталог выглядит глазами клиента.

Описание товара лучше писать так:

```
Диван «Милан» угловой
Габариты: 280 x 160 x 90 см
Материал: рогожка, каркас массив сосны
Цена: 54 900 ₽
```

Фото отправляйте именно как **фото**, а не как файл. Можно отправить сразу несколько фотографий альбомом.

## Данные, логи и резервные копии

| Что | Где лежит |
|---|---|
| База данных (категории, товары, заявки, пользователи) | `database/database.db` (в Docker: `data/database.db`) |
| Журнал текущего запуска | `logs/logs.txt` (в Docker: `data/logs/logs.txt`) |
| Журналы прошлых запусков | `logs/ГГГГ-ММ-ДД_logs.txt` |

**Журнал (логи).** При запуске создаётся `logs.txt`, при остановке бота он переименовывается в файл с датой (например `2026-10-15_logs.txt`), а при следующем запуске создаётся новый. Если за день запусков было несколько, к имени добавляется номер: `_2`, `_3`. В журнале видно, какие кнопки нажимали пользователи и все ошибки с подробностями. Старые журналы можно удалять вручную.

**Резервная копия.** Остановите бота и скопируйте файл базы `database/database.db` (если рядом есть файлы `database.db-wal` и `database.db-shm`, скопируйте и их). Для восстановления положите файл обратно на то же место. Делайте копию перед любым обновлением бота.

> ⚠️ **Фотографии хранятся на серверах Telegram**, а в базе лежат только ссылки на них. Они привязаны к конкретному боту: если вы создадите **нового бота** с другим токеном, старые фото в каталоге не откроются, и их придётся загрузить заново. Токен существующего бота менять безопасно, если вы просто перевыпускаете его в @BotFather.

## Как изменить тексты

Большинство надписей находится в коде, и их можно поменять в любом текстовом редакторе. Сохраняйте файл в кодировке UTF-8 и перезапускайте бота.

| Что изменить | Файл | Что искать |
|---|---|---|
| Приветствие в главном меню | `handlers/backend/start.py` | `INTRO_TEXT` |
| Текст раздела «О компании» | `handlers/backend/start.py` | функция `about_company_handler` |
| Контакты в карточках и в «О компании» | `.env` | `CONTACT_*` (код менять не нужно) |

Не удаляйте при редактировании символы вроде `<b>` и `</b>`: это выделение жирным в Telegram, их надо оставлять парами.

## Частые проблемы

**В консоли: «BOT_TOKEN не задан»**
Файл `.env` не создан или токен не вписан. Проверьте, что файл называется именно `.env` (а не `.env.txt`) и лежит рядом с `main.py`.

**Бот не отвечает**
Проверьте, что окно с ботом открыто и в нём нет ошибок, что есть интернет, а токен в `.env` введён без лишних пробелов и кавычек.

**Админ-панель пишет «нет доступа»**
Ваш Telegram ID не указан в `ADMIN_IDS` или указан с ошибкой. Узнайте ID у @userinfobot, впишите в `.env` и перезапустите бота.

**Не приходят уведомления о заявках**
Администратор ни разу не писал боту. Отправьте боту `/start` с аккаунта администратора.

**Ошибка «terminated by other getUpdates request»**
Один и тот же бот запущен дважды (например, на двух компьютерах или в двух окнах). Оставьте только один запущенный экземпляр.

**Вместо фото в карточках пусто или ошибка**
Это бывает, если токен бота заменили на токен другого бота. Фото нужно загрузить заново (см. предупреждение про фото выше).

**На компьютере с Windows бот останавливается при выключении окна**
Для постоянной работы разместите бота на сервере через Docker или оставьте компьютер включённым.

**Что-то сломалось и непонятно почему**
Откройте `logs/logs.txt` и найдите строки со словом `ERROR`. Отправьте этот файл тому, кто вас поддерживает: в нём вся нужная информация.

## Для разработчиков

Стек: Python 3.11 · aiogram 3 · SQLAlchemy 2 (async) · SQLite · Alembic.

Структура проекта:

```
main.py             точка входа, запуск миграций и бота
handlers/admin/     админ-панель (категории, мебель, удаление, заявки)
handlers/backend/   клиентская часть (/start, каталог, сотрудничество)
database/           engine, модели, CRUD
keyboard/           шаблоны и сборщики клавиатур
settings/           конфигурация из .env
states/             состояния FSM
utils/              фильтры, логирование, общие функции
alembic/            миграции базы данных
```

**Миграции.** При запуске `main.py` миграции применяются автоматически (`alembic upgrade head`). База, созданная старой версией бота (без Alembic), распознаётся и помечается начальной ревизией, данные сохраняются. Ручные команды (из папки проекта):

```bash
alembic upgrade head                            # применить миграции
alembic revision --autogenerate -m "описание"   # создать миграцию после изменения models.py
alembic current                                 # текущая ревизия базы
alembic downgrade -1                            # откатить последнюю миграцию
```

**Переменные окружения** (необязательные):

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `DB_PATH` | Путь к файлу базы | `database/database.db` |
| `LOG_DIR` | Папка для логов | `logs/` |

**Обновление бота:** остановите бота, сделайте копию базы, замените файлы проекта (файлы `.env` и `database/database.db` не перезаписывайте) и запустите заново. Новые миграции применятся автоматически.
